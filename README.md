# Hotel Booking System (CRUD) 🏨

Una aplicación web robusta y ligera diseñada para la gestión y control de reservaciones de hospedaje en tiempo real. El proyecto implementa operaciones CRUD completas y un pipeline eficiente para el seguimiento de la disponibilidad de habitaciones según su categoría.

---

## 🛠️ Arquitectura y Tecnologías

* **Backend:** C# con .NET (Estructura de Controladores / Arquitectura MVC)
* **Base de Datos:** SQL Server / Entity Framework Core (Mapeo Relacional)
* **Gestión de Datos:** Arquitectura limpia para el manejo de endpoints REST y lógica de negocio orientada a objetos.
* **Operaciones Clave:** Operaciones CRUD completas (Create, Read, Update, Delete) para tipos de habitación, usuarios y estados de reserva.

---

## ⚙️ Características Principales

* **Monitoreo en Tiempo Real:** Validación dinámica de disponibilidad de habitaciones para evitar duplicidad de reservas (overbooking).
* **Control de Persistencia:** Consultas optimizadas en base de datos relacional para garantizar la consistencia de los estados del hotel.
* **Diseño Orientada a Objetos:** Modelado estructurado en C# para representar de forma escalable las entidades del negocio (Rooms, Bookings, Guests).
